# Software

Period-accurate software to run on the machines once they're up. The idea here
is to have things that were actually being used at the time running on the
hardware, not just get the OS installed and call it done.

Right now this is focused on the web. 1993/1994 was right when the web started
to become a thing people actually used, and NCSA was right in the middle of
that. Having a working web server and browser running on a 486 from that era
is a pretty good demo for VCFMW.
